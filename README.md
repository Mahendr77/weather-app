# Weather App

## Project Description
The Weather App is a web application that displays weather information for a selected city or location.

## Features
- Search weather by city name
- Get weather using the My Location option
- Display current temperature
- Show humidity and wind speed
- Display a five-day weather forecast
- Provide weather tips and alerts
- Responsive user interface

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- OpenWeather API

## Project Files
- index.html – webpage structure
- style.css – webpage design
- script.js – frontend functionality
- server.js – backend and API communication
- .gitignore – excludes sensitive and unnecessary files

## How to Run the Project
1. Install Node.js.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run `npm install`.
5. Create a `.env` file and configure your OpenWeather API key.
6. Run `node server.js`.
7. Open the frontend using your local development server.

## Security
The API key is stored in the `.env` file and should not be uploaded to GitHub.
